# 🌸 Image Gallery

A simple image gallery created using HTML and CSS to practice flexbox layout that displays flower images in a flexible layout with titles and descriptions.

## 🌐 Live Website

https://inthusha20241647-commits.github.io/image-gallery/

## ✨ Features

* 📱 Responsive flexbox layout
* 🌺 Flower image cards
* 🏷️ Image titles and descriptions
* 🎨 Custom styling using CSS
* 🔤 Google Poppins font

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 CSS3
* 📦 Flexbox
